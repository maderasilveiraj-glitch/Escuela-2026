CORE ACADÉMICO v4.14 — WINDOWS

1. Instala Node.js LTS en Windows.
2. Abre esta carpeta.
3. Haz doble clic en BUILD-WINDOWS.bat.
4. El instalador y la versión portable aparecerán en dist.

CHATGPT / OPENAI
- Abre Core Académico y entra a “IA + ChatGPT”.
- Pulsa “Configurar ChatGPT”.
- Pega tu API key de OpenAI.
- La clave se guarda protegida en el equipo mediante Electron safeStorage cuando está disponible.
- Las preguntas pueden incluir texto y varias imágenes.
- Core Académico muestra su respuesta local y ChatGPT muestra la respuesta de OpenAI lado a lado.

Importante: el uso de la API de OpenAI puede generar cargos según tu cuenta y modelo. La app no incluye una clave propia.

# Core Académico v4.1 — Diseño unificado y 15 temas

Esta versión mantiene la funcionalidad de Core Académico y unifica la estética de todas las páginas con el lenguaje visual de la página **Enlaces**: tarjetas tipo glassmorphism, bordes suaves, profundidad, transparencias y acentos por tema.

## Temas visuales

Hay **15 temas** disponibles desde el botón 🎨 Tema del menú:

1. Cerámico
2. Glacial
3. Océano
4. Esmeralda
5. Violeta
6. Rosa
7. Coral
8. Ámbar
9. Lima
10. Turquesa
11. Cielo
12. Índigo
13. Ciruela
14. Pizarra
15. Medianoche

Los temas no cambian la estructura ni la distribución de las páginas: sólo modifican la paleta de colores de fondos, textos, bordes, botones, tarjetas, indicadores y sombras.

## Compatibilidad

- GitHub Pages
- Sin backend
- Datos locales mediante `localStorage`
- Mantiene Enlaces, Post-its, Kardex, tareas, metas, asistencia, calculadoras y demás módulos del proyecto.
